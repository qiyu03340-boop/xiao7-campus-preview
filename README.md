# 小7校园AI v2.7.2 响应式网站

## 设备适配
- 小屏手机：320px 起
- 常见手机：360px、375px、390px、430px
- 平板：768px、820px、1024px
- 电脑：1280px、1440px、1920px
- 支持 iPhone 安全区域、安卓全面屏、横屏、软键盘和高分屏

## 使用方式
必须保留整个目录结构，不要只复制 `index.html`：

- `index.html`
- `assets/images/`
- `assets/icons/`
- `data/`
- `manifest.webmanifest`

本地预览建议通过 HTTP 服务打开，或将整个文件夹上传到 GitHub Pages、Cloudflare Pages、Vercel、Netlify。

## GitHub Pages
仓库根目录应直接包含 `index.html`、`assets`、`data` 和 `manifest.webmanifest`。发布源选择 `main` 分支根目录。
